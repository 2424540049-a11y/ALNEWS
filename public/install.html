网页应用

手机版与电脑版使用同一应用，界面会随设备尺寸调整。

查看安装步骤 ↓ 直接打开工作台

安装需要在浏览器或系统提示中确认。

按设备安装

  1. iPhone / iPad：在 Safari 打开本页，点击分享，选择“添加到主屏幕”，再点击“添加”。
  2. Android：在 Chrome 或 Edge 的菜单中选择“安装应用”或“添加到主屏幕”。
  3. 电脑：在 Chrome / Edge 的地址栏或菜单中安装；Mac Safari 可使用“添加到程序坞”。
其他设备的安装步骤

iPhone / iPad · Safari

分享 → 添加到主屏幕 → 添加。如果看到“作为网页 App 打开”，保持开启。

Android · Chrome / Edge

右上角菜单 → 安装应用 / 添加到主屏幕 → 按系统提示确认。

电脑 · Chrome / Edge

地址栏的安装图标，或浏览器菜单中的“安装应用 / 应用” → 确认安装。

Mac · Safari

支持网页应用的 macOS：Safari 的“文件”菜单或分享按钮 → 添加到程序坞 → 添加。

也在手机上使用

复制安装链接，发到自己的手机，在浏览器中打开。

当前为本机预览；手机安装请使用正式上线后的 HTTPS 链接。

安装后仍需联网获取行情和新快讯。若浏览器没有安装入口，可先使用网页版；已经安装过的设备，也可从应用图标打开。
