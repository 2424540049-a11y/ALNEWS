# 铝双轨20（研究）：理想价格回顾性比较

研究日期：2026-10-04。对象：沪铝主连 `nf_AL0` 日线。新策略 key：`al_channel_20`。

用户要求在理想价格口径下，最近1、3、6、12个月均超过“铝更新1”和“铝-1Best”。40组固定规则候选中，`candidate-33` 满足这四个窗口的已平仓复利收益要求。它是看过这四个窗口结果后选出的回顾性研究候选，**这四组结果不能再当作独立样本外验证，更不能保证未来收益**。其过去12个月平仓13次，少于Best的15次，没有通过增加杠杆或高频刷信号获得比较优势。

**关键核验：改为信号出现后下一根开盘成交，新策略四个窗口均为负收益；2022—2025-09-29验证区间也为负收益。因此没有证明可实现的全面胜出或稳定优越性。** 本报告保留用户指定理想价格，不修改原策略规则，不隐瞒这一差异。

## 固定策略规则

20根收盘价简单均线，中轨上下各0.5倍总体标准差。收盘价**严格高于**上轨变为多头，**严格低于**下轨变为空头，轨内保持原方向；满20根之前空仓。方向变化才记一条买入或卖出信号。同价触轨不触发。无日期判断、窗口专用参数、加杠杆、未来数据、额外止盈止损或仓位优化。

纯函数实现：`candidate-channel.js`。研究脚本以`family=bollinger_close, period=20, multiplier=0.5`运行，测试确认与纯函数完全一致。40组候选全部通过5段历史前缀检验：追加未来K线不会改写历史信号。

## 同口径回测结果

三个策略均为双向、相同1倍价格敞口；窗口开始空仓；**只复利统计窗口内已经平仓的交易，期末未平仓不计入标题收益**，不扣手续费、滑点和换月成本。这与原软件一致，不是期货保证金收益率。原理想价格为买入取信号当根最低价、卖出取当根最高价；信号使用当根收盘价，交易时无法预知该日高低点，因此这是事后理想化模拟。日内高低点发生先后也未知。

“逐日回撤”另按每天收盘对持仓估值，包含未平仓浮盈亏，是对风险的补充，不是原软件仅平仓收益序列的回撤。次根开盘列保持相同策略和仓位、只把所有成交顺延到下一根开盘（该开盘必须落在窗口内）；仍未计费用。

## 候选范围与选择过程

在本次研究中一共评价40组候选，完整参数、所有训练/验证/四窗口成绩在`results.json`，没有删除失败候选：

- Supertrend：ATR周期10/14/20，倍数2/2.5/3/3.5，共12组。
- EMA差值/ATR缓冲：快慢均线5/20、10/40、20/60、20/120，缓冲0/0.5/1倍ATR14，共12组。
- 前高前低Donchian通道：10/20/40/60根，共4组。
- 收盘确认双轨：周期10/20/40/60，标准差倍数0/0.5/1，共12组。

预先定义训练区间2010-01-01—2021-12-31，验证区间2022-01-01—2025-09-29，最终比较窗口从2025-09-30起。预设排名先要求训练区间次根开盘已平仓收益非负，再最大化验证区间次根开盘收益 / max(10%, 逐日最大回撤绝对值)。这个独立于四窗口收益的排名选择的是`candidate-34`（20日±1σ），它没有满足用户四窗口全胜要求；它的验证收益也为负。

本次最终加入应用的是满足用户指定理想价格四窗口要求的`candidate-33`，**属于观察最终比较结果后的人工选择**，不是上述独立排名的最佳者。该候选训练区间次根开盘收益+134.98%，验证区间-31.62%，验证逐日最大回撤-42.66%。近期理想价格漂亮但成交敏感性核验和更早验证失败，不能据此宣称策略在实际交易中优于两旧策略。

## 复现命令

在项目根目录（Node 20+）执行：

```sh
node research/strategy-lab.cjs
node --test research/strategy-lab.test.cjs
```

脚本读取固定快照，不重新联网取数；`results.json`记录40候选，`run-summary.json`为初始运行控制台输出。应用日后取得新数据，窗口终点和结果会自然变化，不保证持续四窗口全胜。

## 方法参考

反复在同一历史样本筛选候选会提高偶然优胜的机会，因此这里完整保留40次试验，并明确区分回顾性四窗口比较与独立验证。此处遵循[Bailey等，《The Probability of Backtest Overfitting》](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)讨论的多重试验披露原则；本研究没有计算论文定义的PBO，也不声称已完成论文的CSCV检验。
